# Limites de segurança e relato

Este repositório é um projeto de portfólio local com dados sintéticos. Não é um serviço financeiro em produção e não deve receber informações reais de clientes. O README documenta as fronteiras de autenticação, persistência e operação.

O processo de validação inclui auditoria de dependências e uma varredura de assinaturas de segredo. Isso não substitui revisão independente ou uma avaliação de segurança completa.

Se identificar uma falha, descreva o cenário com dados sintéticos. Não inclua tokens, senhas ou identificadores pessoais em issues públicas. Não teste a hipótese em sistemas de empresas ou ambientes de terceiros.
