# Revisão e contribuição

Para revisar este projeto, use Python 3.12 e `requirements-dev.txt`, execute `python scripts/verify.py` e confira os contratos em `docs/openapi.json`.

Uma issue útil descreve entrada sintética, resultado esperado, comportamento observado, versão da fonte e reprodução mínima. Uma proposta de alteração deve preservar os contratos ou explicar a mudança e incluir o teste correspondente. Não envie dados pessoais, chaves, dados de clientes ou dumps de ambientes reais.

Achados de segurança devem ser relatados de forma responsável, sem publicar credenciais ou explorar sistemas de terceiros. Este repositório é um laboratório local; os testes não devem apontar para produção.
